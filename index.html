How it works

Event-driven.
Risk-managed.

Every book update triggers a requote. Every fill updates inventory. Every position has a stop-loss.

01
Market selection
Ranks open Polymarket CLOB markets by MM profitability score. Filters out extreme probabilities, zero-fee geopolitics, and low-volume markets.
02
Real-time book feed
WebSocket connection to Polymarket's market channel. Handles all 7 event types including tick_size_change — critical, must update immediately or orders are rejected.
03
A-S quote computation
Computes optimal bid/ask using Avellaneda-Stoikov in logit space. Inventory skew reduces adverse selection. Fee-aware minimum spread ensures profitability.
04
Order placement + builder code
Cancels stale orders when price moves >0.5%. Places new bid/ask via py-clob-client-v2 with builder code attached. Stop-loss exits market if unrealized PnL breaches threshold.
Quoting formula
# Reservation price (logit space)
r = logit(mid) − q·γ·σ²·(T−t)

# Optimal quotes
bid = sigmoid(r − δ/2)
ask = sigmoid(r + δ/2)

# Fee-aware minimum spread
min_spread = feeRate·p·(1−p)^exp
# Taker fee (post March 2026)
fee = C × feeRate × p × (1−p)^exp

# exp varies by category:
Crypto / Sports / Politics → 1
Economics / Weather → 0.5
Other / General → 2
Ref: arXiv:2510.15205 · Avellaneda & Stoikov (2008)
